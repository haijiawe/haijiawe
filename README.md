## 关于我

`haijiawe`。

事情基本是让 Agent 跑出来的：我提需求、看结果、不对就改。卡住了就先停下，不死磕——换个路子或者放两天，比在原地耗着强。

没正经学过，属于边做边补。技术栈以 **TypeScript** 和 **Rust** 为主，其他按项目需要临时上手。

> 先跑通，再做好。
