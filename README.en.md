## About

`haijiawe`.

Most of what I build comes out of agents doing the work: I write the request, check the output, redo it when it's wrong. When I get stuck I stop — switch routes or leave it for a couple of days. Grinding in place is worse than walking away.

No formal training; learning on the job. My main stack is **TypeScript** and **Rust**, everything else gets picked up per project.

> Ship it first, then make it good.
